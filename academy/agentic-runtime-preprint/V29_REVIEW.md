# v29 review and release record

The revision makes the Data Wiki / Theme Wiki / Intermediate Relation boundary
executable while preserving v28's contract-centered runtime thesis. It adds
execution-time revalidation, a request-bound ticket, evidence envelopes, a
conditional soundness argument, and an explicit dependency-invalidation rule.

The new artifact is a single-process reference model. Its 1,024 synthetic fault
combinations agree with the declared oracle and five lifecycle tests pass. This
is finite conformance, not a production benchmark or validation of P1. Natural
retrieval tasks, multiple data sources, a deployed runtime and distributed
performance experiments remain required.
